# Sandcastle Unblocked

A small browser game inspired by beach-defense arcade titles: defend your sandcastle from enemy ships arriving from the sea, switch between cannons, and survive increasingly difficult waves.

## How to play

1. Open `index.html` in any modern browser.
2. Move the mouse to aim.
3. Click or press Space to fire.
4. Use 1, 2, and 3 to switch weapons.
5. Press E or use the upgrade button to improve the currently selected weapon.
6. Survive the waves and keep the shoreline safe.

## Weapons

- Cannonball: reliable direct shot
- Bounce Shot: ricochets once to hit tricky angles
- Explosive Shell: deals area damage around impact

## Files

- `index.html` — UI shell
- `style.css` — beach theme and layout
- `game.js` — gameplay loop, enemy logic, combat, and upgrades

## Notes

This version is designed to run without any build step or external libraries.
